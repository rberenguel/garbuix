# garbuix

> de l’it. _garbuglio_, íd., probablement resultat d’un encreuament de _groviglia_ ‘embull de fils’ (del ll. _globus_ ‘cabdell’) i _bugliare_ (ll. _bullire_ ‘bullir’)
> **Barreja confusa, embolic.**

Tangle or mess.

---

This is the concept map helper(s) and the graphviz renderer I had embedded in [Weave](https://github.com/rberenguel/weave).

Most of my use of Weave for the past 3-4 months has been just using this, hence I think it is way better to isolate it and improve it.

Maybe even add tests to the fancy functionalities (currently those are likely broken, I haven't tried).
