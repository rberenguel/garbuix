Garbuix

From Catalan, tangle or mess. Github

On the left hand side ☜ you have a resizable, editable text field where you can write a simplified form of the dot language used by Graphviz, while on the right ☞ you will find the rendered Graphviz, scrollable and zoomable. Not downloadable yet though.

If the border of the render turns red, it means you have some error: press Cmd-G to switch between the main view (simplified and rendered) and a view with the generated dot and potential errors. You can copy the generated dot and run graphviz locally to generate SVGs, PNGs, etc.

There is still not a lot of documentation on the syntax, but you can find some pointers here:

  • The main-example.cmap file you get when you start
  • Basic description I used as an initial spec
  • Examples folder: open these and copy-paste on the left side panel to see what can be done

You can save your diagram (with a cmap extension, for concept map) with Cmd-S, and can load with Cmd-O. You can also tell your operating system to open any cmap file with Garbuix. You can recover the basic example with Cmd-P and choosing the obvious option. The other one is for fun, turn on the volume and type.

If you are not on a Mac, you can use Ctrl everywhere I mention Cmd above.
